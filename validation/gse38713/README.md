# GSE38713：真实公开数据再分析与论文结论对照

## 结论与证据等级

已实际下载GEO处理后表达矩阵、GPL570注释并调用HerbInsight正式差异分析函数计算，不是读取原案例结果或模拟数据。

本次结果与原论文摘要的部分表达模式相容：摘要点名的7个缓解期异常基因均达到本次全基因BH<0.05；REG1A、IL8/CXCL8在活动期显著升高，在缓解期未检出显著差异。

**这属于同一发现数据的探索性再分析，不是独立外部验证，不是全文严格复现，更不能证明五积散疗效。** 摘要未逐一说明7个基因的升降方向，所以只比较其“是否存在差异”，不声称7个方向全部与论文吻合。未显著不能视为等效或恢复正常。

## 事先确定的对照与处理

在查看本次计算结果前，根据摘要固定9个基因：REG4、S100P、SERPINB5、SLC16A1、DEFB1、AQP3、AQP8、REG1A、CXCL8（摘要旧称IL8）。不按本站P值挑选一致的基因。

按GEO source_name分组：13例非炎症对照、8例缓解期、15例活动期受累黏膜。另7份活动期非受累黏膜与部分受累标本具有配对结构，排除于本次独立两组比较。两项比较共享同一对照组，不能当作两次独立验证。样本来源和纳入情况见sample_audit.csv。

使用提交者GC-RMA规范化的log2表达，不重复取对数。按提交者所述规则保留全43份中至少1份表达≥5的探针；排除空基因符号及一对多探针；同基因多探针取log2表达中位数。54,675个输入探针最终保留20,082个探针、11,753个基因。探针排除明细保存在本地probe_mapping_audit.csv。

调用`src.expression_analysis.differential_expression`：独立双侧Welch检验，病例减对照的平均log2差；每项比较对全部11,753个基因BH校正。关键基因比较采用BH<0.05，不另设倍数门槛，不只对9个候选基因校正。未重做CEL质控/GC-RMA，也未复制原论文完整预处理与统计设计。

## 软件数值复核

另用Welch自由度公式和不完全Beta函数计算全基因双侧P值，不调用ttest_ind；独立排序和累积最小值计算BH。两项比较的P与BH最大绝对差均要求<1e-10，实际数值见summary.json及methods文件。此检查验证的是数值实现，不验证疾病因果机制。参考实现仍使用SciPy特殊函数，并非另一个独立统计软件环境。

## 尚不能下的结论

- 不能证明“缓解期恢复正常”：非显著可能与样本量、方差有关，需要预设等效界值并做等效性分析。
- 没有校正年龄、性别、药物、部位或潜在批次等混杂；未发现明确批次字段不等于不存在批次。本次是描述性/探索性比较。
- 原研究关注UC缓解期黏膜，不是五积散干预试验；不能外推药物作用或临床疗效。
- 未计算真实GO/KEGG或重复论文的蛋白实验、29基因验证队列；这9个摘要点名基因不能代表全论文复现率。
- 真实数据再分析不证明教学效果；真人试用仍待完成。

本地raw目录另有remission_validation.zip和active_validation.zip，内含可直接用于本站的expression_log2.csv、sample_metadata.csv、完整结果与方法记录。选择已有log2数据、control为对照、remission或active为病例；上传界面仍需如实核查独立样本与设计限制。不要将本研究混杂未调整的结果解释为干预效应。
