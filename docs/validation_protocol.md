# 真实数据复核方案

状态：本版本有软件自动化回归检查；尚未完成新增的、具备完整来源与授权记录的真实公共数据独立复核。现有五积散案例不因此自动获得科学验证。纠错题和内置演示均不能代替真实数据验证。

## 选择与获取
选择公开表达数据时，从GEO条目记录accession、原始论文、物种、组织、平台、样本分组、受试者、批次、下载地址、日期及使用条款。未确认授权或去标识化前不把原始材料上传到公开仓库。必须保存未经修改的下载文件与SHA256。

## 本站方法的适用性门槛
仅选适用于本站独立两组Welch教学方法的已规范化log2表达数据：每组至少3个独立样本，无配对/重复受试者或需调整的批次。原始计数不能直接输入；含复杂协变量的研究应使用适合其设计的外部方法。不能为符合本站界面隐瞒设计问题。

## 输入与预处理记录
记录探针到基因映射版本、一对多和多探针处理、缺失与低表达过滤、标准化与log转换来源；不把测试标签用于机器学习特征筛选。输出gene_symbol×sample矩阵及sample/group表，核对样本ID；共享前确认许可。

## 同方法参考复算
以固定输入、固定case/control方向运行本站Welch与BH。同时使用独立R脚本逐基因t.test(case, control, var.equal=FALSE)，并用p.adjust(p, method='BH')对同一有效检验集合校正。排除或特殊处理零方差项的策略必须一致。
保存两端软件版本、代码、输入hash、参数、结果和最大绝对差；P值/校正P值可预设绝对误差1e-8，log2差1e-10，超出即调查。limma/DESeq2的方法不同，不能以其结果不一致直接判定Welch实现错误。

## ORA与PPI
ORA记录注释版本、条目全集、可检出背景和未匹配基因；用相同N/K/n/k和同一多重检验族独立复核。PPI记录来源、网络类型、分数尺度、阈值、孤立点策略；拓扑参考使用同图同定义。绝不只挑显著或一致的结果报告。
