# HerbInsight 内容表达规范

## 信息顺序
每节围绕一个问题组织：本节目标 → 操作步骤 → 实际输入 → 结果解读 → 文件交接。来源与方法说明放在内容附近，详细复现记录按需展开。避免额外增加同义菜单或重复模板。

## 两种语气
- 标题、指标、报告：准确、简洁，用方法和任务命名，如“差异表达分析”“文件交接”“方法与资料完整性”。
- 操作讲解：自然口语但不卖弄，使用“先看”“接着”“把这张表保存下来”“一起读结果”。解释动作的理由，避免“显然”“随便”“秒懂”“一键发现机制”等表达。

## 信息状态
- 正常操作说明用正文，不把每条指导都放进黄色警告框。
- 数据错误、输入不适用、结果不一致等需要当前采取行动的问题保留警告/错误状态。
- 模拟数据、归档案例与现场计算在入口明确标识；结果附近保留关键解释边界。
- 材料缺失在摘要处说明状态，细节收进方法说明；不因竞赛展示而删掉缺失记录或验证限制。

## 科学措辞
“候选”“关联”“预测”“富集”“因果假设”按证据使用；非显著不等于等效，高AUC不等于临床有效。格式校验不等于科学审核。实际功能变化时同步修改课程、能力表和下载文档，避免旧入口与旧能力说明。

## 维护检查
保留字段名、算法名、样本量条件、阈值和版本含义。修改文案时避免更改计算逻辑、默认参数和输入保护。界面按钮文字变化后同步核对自动化测试。
