# HerbInsight：评审演示与能力边界

## 作品定位
面向中医药与生命科学初学者的网络药理学教学实训平台。帮助学习者理解资料来源与输入规范，在传统网站/软件路线与本站计算之间作出有依据的选择。
教学设计特色是把错误识别、修复反馈和可追溯分析放在同一课程中；不是宣称提出新算法。

## 建议录制一个4分钟任务，而不是浏览所有菜单
1. 0:00–0:30：学习路线介绍对象、任务、输入和交付物。说明五积散案例用于教学，不是临床疗效证明。
2. 0:30–1:15：进入资料整理，完成ID纠错挑战；展示原始ID与映射状态为何不能丢失。
3. 1:15–2:00：进入PPI第7步，用标明来源的演示边表运行计算，展示输入列和阈值。说明平台不自动抓取STRING。
4. 2:00–3:00：进入GO/KEGG，先比较纠错题的两种背景，再展示课程第6步的实际ORA计算。若使用模拟注释，必须口头和画面标明模拟，不能称为真实GO发现。
5. 3:00–3:40：导出计算结果及参数记录，解释富集关联不能证明因果。展示纠错学习记录。
6. 3:40–4:00：说明验证状态、贡献与AI辅助范围，以及真人试用尚待完成的部分。

## 可现场核验
- 课程与计算同入口，无需额外实验室菜单。
- 纠错题需要提交；错误选项有解释，允许改正，学习记录保留首次是否正确及尝试次数。
- 上传计算受输入设计约束，参数/输入变化后旧结果不应继续冒充新结果。
- 转录组：已规范化log2表达上的独立两组Welch检验，不是DESeq2或limma。
- 机器学习：训练折内预处理和筛选；内部留出结果不是外部验证。
- 免疫：ssGSEA相对评分，不是细胞比例。MR：预先去连锁的工具变量表及限定IVW，不提供自动GWAS搜索或完整因果保证。
- 细胞通讯为工具教学；计算扰动不等于生物学敲除实验证明。
