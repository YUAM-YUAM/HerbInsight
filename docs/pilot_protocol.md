# 初学者试用协议与空白记录

状态：待真实参与者执行。没有招募人数、成功率或教学提升结果可报告。

## 对象与伦理
建议自愿邀请6–10名有基础生物学背景、缺少网络药理学经验的同学。不收集姓名、学号、患者数据；以P01等随机编号记录。说明可退出，仅用于改进作品；录屏需单独同意，发表结果前确认同意范围。

## 两项可比较任务
A：根据一份已给定映射的模拟靶点表，保留原始ID，整理统一基因列表和未映射清单，解释为什么不能仅做字符串去重。
B：根据表达列名与打乱的分组表，检查重复/缺失样本并生成匹配表，解释为什么不能按行贴分组。

每项准备难度相近的两个版本（数量相同、ID不同）。若比较静态教程与平台：一半参与者先用静态教程完成A、再用平台完成B；另一半反序，并平衡题目版本。两种条件提供相同背景知识、时限与评分标准，不把先学到的答案直接重复用于第二条件。小样本只能说明可用性线索，不能据此宣称显著教学优势。

## 操作
先记录背景与是否做过类似任务；限时10分钟，不代替参与者操作。分别记录完成用时、求助次数、错误类型及能否独立解释。使用不含姓名的观察笔记；失败和退出也要记录。最后问“哪一步最困惑、入口在哪里、下一步是什么”。

## 理解题与判定
1. 为什么不同ID可能是同一基因？满分应提到映射、物种和证据，而非仅大小写。
2. 为什么样本数相同仍可能分组错误？满分应提到ID连接、顺序、唯一性与集合一致。
3. 富集显著能证明治疗机制吗？满分应否定并指出背景、注释偏差与实验验证需求。

## 汇总边界
如实报告有效人数与缺失记录，优先给出完成数/总数、用时中位数与范围、常见错误和迭代改动。不要把反复练习后的正确率说成首次掌握率；不编造数据或选择性排除失败者。
